# Ветеринарный центр & СПА-Груминг «Лапки & Хвостик»

Готовый к запуску, высококонверсионный адаптивный лендинг для ветеринарной клиники доказательной медицины и салона бережного СПА-груминга.

## 🐾 Особенности проекта

- **Фирменная палитра и типографика:**
  - Небесно-бирюзовый (`#0284C7`) — символ чистоты, доверия и передовой медицины.
  - Тёплый персик (`#FDBA74`) — дружелюбие, забота и мягкость.
  - Мягкая лаванда (`#DDD6FE`) — спокойствие, снятие тревожности и стресса (Fear-Free).
  - Тёплый белый (`#FAFAF9`) и графитовый (`#334155`).
  - Шрифтовая пара Google Fonts: **Fredoka** (округлые, мягкие, дружелюбные заголовки) + **Inter** (чистый, читаемый интерфейсный текст).
- **Интерактивный ветеринарный экспресс-триаж (Triage Assistant):**
  - Пошаговая оценка состояния питомца по симптомам и критическим «красным флагам».
  - Моментальное определение уровня срочности (Красный — Экстренно 24/7, Желтый — Приём в течение 2-4 часов, Зеленый — Плановый визит).
  - Автоматическая передача собранных данных триажа в модальное окно записи.
- **Интерактивная карта Яндекс (API 2.1):**
  - Координаты клиники в Хамовниках `[55.728912, 37.568341]`.
  - Кастомная фирменная метка с информацией о графике, метро и парковке.
  - Автономный fallback с прямой ссылкой на построение маршрута в Яндекс Навигаторе при отсутствии интернета или блокировке скриптов.
- **Динамический индикатор режима работы («Открыто сейчас»):**
  - Автоматически рассчитывает текущее московское время (UTC+3) и отображает статус клиники в реальном времени.
- **Модальное окно онлайн-записи и маска телефона:**
  - Удобная форма с выбором питомца, врача, даты и времени.
  - Маска телефонного номера в формате `+7 (___) ___-__-__`.
  - Встроенная валидация полей и экран подтверждения с номером талона.
- **Интерактивное До / После груминга:**
  - Наглядные карточки преображения питомцев до и после процедур с описанием комплекса и комментариями грумеров.
- **Фильтрация каталога услуг:**
  - Мгновенное переключение по категориям: Терапия, Диагностика, Хирургия, Груминг, Профилактика.
- **Адаптивность 100%:**
  - Полноценное мобильное выдвижное меню (Drawer), быстрые плавающие кнопки вызова и записи для мобильных пользователей.

## 🗺️ Как изменить координаты Яндекс Карты

1. Откройте [Яндекс Карты](https://yandex.ru/maps) и найдите адрес вашего здания.
2. Кликните правой кнопкой мыши по точке здания и скопируйте координаты широты и долготы (например, `55.728912, 37.568341`).
3. В файле `script.js` укажите их в объекте `address.coordinates`:
   ```javascript
   coordinates: [ВАША_ШИРОТА, ВАША_ДОЛГОТА],
   ```
4. Обновите ссылку для навигатора в `address.yandexMapsLink`:
   ```javascript
   yandexMapsLink: "https://yandex.ru/maps/?rtext=~ВАША_ШИРОТА,ВАША_ДОЛГОТА",
   ```
5. Если требуется собственный API-ключ Карт (для высоконагруженных сайтов с > 25 000 просмотров в сутки), укажите его в `index.html` в теге подключения скрипта:
   ```html
   <script src="https://api-maps.yandex.ru/2.1/?apikey=ВАШ_API_КЛЮЧ&lang=ru_RU" type="text/javascript"></script>
   ```

## 📷 Как заменить фотографии на собственные

В коде `index.html` все изображения снабжены комментариями с подсказкой:
`<!-- КАК ЗАМЕНИТЬ ФОТО: Замените src на images/... -->`

Рекомендуется создать папку `images/` в каталоге `landing-14` и разместить оптимизированные файлы:

| Секция | Рекомендуемое имя файла | Назначение и размер |
|---|---|---|
| **Главный экран** | `images/hero-vet.jpg` | Фото врача с собакой (1200x800px, WebP/JPG) |
| **До / После груминга** | `images/grooming-dog-before.jpg` / `after.jpg` | Фото питомца до и после стрижки (800x600px) |
| **Врачи** | `images/doctor-1.jpg` ... `doctor-4.jpg` | Портреты специалистов в медформе (800x900px) |
| **Галерея клиники** | `images/clinic-reception.jpg` | Холл, операционная, стационар (1000x700px) |

## 📩 Подключение отправки заявок (Telegram, CRM, Email)

В функции `initBookingModal()` в `script.js` перехватывается отправка формы. 
Чтобы отправлять данные в ваш **Telegram-чат** или **CRM-систему (Битрикс24, amoCRM, YClients)**, замените блок имитации отправки на `fetch`:

### Пример отправки в Telegram Bot:
```javascript
const BOT_TOKEN = "ВАШ_ТОКЕН_БОТА";
const CHAT_ID = "ВАШ_CHAT_ID";

const text = `🐾 Новая запись в Лапки & Хвостик!\n` +
             `Талон: ${randomTicket}\n` +
             `Питомец: ${petNameInput.value} (${document.querySelector('input[name="modal_pet_type"]:checked').value})\n` +
             `Услуга: ${serviceInput.value}\n` +
             `Владелец: ${ownerNameInput.value}\n` +
             `Телефон: ${phoneInput.value}\n` +
             `Дата/Время: ${document.getElementById('form-date').value} (${document.getElementById('form-time').value})\n` +
             `Симптомы: ${document.getElementById('form-notes').value || 'Не указаны'}`;

fetch(`https://api.telegram.org/bot${BOT_TOKEN}/sendMessage`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ chat_id: CHAT_ID, text: text })
});
```

## 🚀 Локальный просмотр и размещение на хостинге

### Локальный запуск:
Страница является полностью автономным статическим веб-сайтом (Pure HTML/CSS/JS) без внешних npm-сборок.
Вы можете запустить её локально любым способом:
- Открыть `index.html` прямо в браузере.
- Либо через локальный сервер:
  ```bash
  cd /Users/egor/Desktop/lendigs/landing-14
  python3 -m http.server 8080
  # Откройте в браузере: http://localhost:8080
  ```

### Размещение на хостинге:
1. Загрузите файлы `index.html`, `style.css`, `script.js` и папку `images/` в корневую папку сайта (`public_html` или `www`) на любом хостинге (Timeweb, Beget, REG.RU, cPanel).
2. Или подключите репозиторий к **GitHub Pages**, **Vercel** или **Netlify** — проект запустится мгновенно за пару секунд.
