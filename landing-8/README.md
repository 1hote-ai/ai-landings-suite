# FLEUR Botanical Atelier — Органическое флористическое ателье и бутик редких сортов

Премиальный, полностью готовый к продажам лендинг для флористического ателье, цветочного бутика авторских композиций и сервиса регулярной цветочной подписки.

* **Дизайн-концепция:** Романтическая флористическая редакция (Romantic floral editorial), лёгкая пастельная ботаника, деликатная антиква, асимметричные карточки.
* **Цветовая палитра:** Пыльная роза (`#D8A49B`), Шалфейный ботанический зелёный (`#5C6B5E`), Лепестковый румянец (`#FBF4F2`), Глубокий лесной изумруд (`#27382B`), Мягкое шампанское (`#F4E8DF`).
* **Типографика:** `Italiana` (акцентные заголовки) + `Jost` (чистый геометрический гротеск).
* **Готовность:** 100% рабочий продакшн-код без заглушек, с реальным убедительным копирайтингом на русском языке.

## 🕒 2. Живой статус работы («Открыто сейчас»)

На сайте реализован динамический расчет рабочего статуса ателье с учетом часового пояса Москвы (`Europe/Moscow`):
- Если текущее время попадает в интервал работы: отображается зелёный пульсирующий индикатор и текст вида: `Открыто сейчас • до 21:00` (или `до 20:00` в выходные).
- Если бутик закрыт: отображается статус `Сейчас закрыто • откроется в 09:00` (или `в 10:00`).

Статус обновляется каждую минуту автоматически без перезагрузки страницы.

## 🗺️ 3. Настройка Яндекс.Карт и координат

Карта подключена через официальный API Яндекс.Карт 2.1 в файле [`index.html`](file:///Users/egor/Desktop/lendigs/landing-8/index.html):
```html
<script src="https://api-maps.yandex.ru/2.1/?lang=ru_RU" type="text/javascript"></script>
```

### Как изменить координаты бутика:
1. Откройте [Яндекс.Карты](https://yandex.ru/maps/), найдите нужный адрес или кликните правой кнопкой мыши по точке, чтобы скопировать координаты (например: `55.755864, 37.617698`).
2. В файле [`script.js`](file:///Users/egor/Desktop/lendigs/landing-8/script.js) замените массив в параметре `coordinates`:
   ```javascript
   coordinates: [55.755864, 37.617698],
   ```
3. Метка на карте, центр обзора и ссылки построения маршрута обновятся автоматически.
4. Если API недоступен или заблокирован контент-фильтром, карта плавно переключается на встроенную элегантную плашку с адресом и прямой кнопкой открытия приложения «Яндекс.Карты».

## 🎨 5. Интерактивный конструктор букета

Пользователь может:
1. Выбрать повод (День рождения, Признание в любви, Свадьба, Благодарность, Дом).
2. Выбрать палитру эмоций (Пыльная роза, Пастель, Изумруд, Карамельный закат). Фото предпросмотра мгновенно адаптируется под палитру.
3. Выбрать масштаб:
   - **Petit** (30 см) — 4 900 ₽
   - **Grand** (45 см) — 8 900 ₽ (Хит)
   - **Imperial** (65 см) — 15 500 ₽
4. Добавить дополнения (Каллиграфическая открытка бесплатно, дизайнерская ваза +1 800 ₽, соевая свеча +1 400 ₽, крафтовый шоколад +950 ₽).
5. Выбрать дату и временной интервал доставки.
6. Нажать кнопку **«Оформить этот букет»** — модальное окно заказа откроется уже с полным расчетом, списком компонентов и суммой.

## 📞 6. Форма захвата лидов и маска телефона

* Форма заказа снабжена строгой маской ввода российского номера: `+7 (___) ___-__-__`.
* Обрабатываются вставка из буфера обмена (автоматическое преобразование номеров, начинающихся с `8` или `9` в `+7`), клавиша Backspace и валидация длины (строго 11 цифр).
* Проверяется наличие имени (от 2 символов) и обязательное согласие с политикой конфиденциальности.
* При отправке симулируется запрос к серверу с отображением спиннера, после чего генерируется уникальный номер заказа (например, `#FL-8492`), а форма переходит в экран благодарности с деталями заказа.

## 🚀 7. Локальный запуск

Проект написан на чистом ванильном стеке (HTML5, CSS3, ES6 JavaScript) без необходимости сборщиков Webpack/Vite:

cd /Users/egor/Desktop/lendigs/landing-8

python3 -m http.server 8008
