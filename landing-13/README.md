# HOP & BARREL / ХМЕЛЬ & БОЧКА
### Премиальный готовый лендинг крафтовой пивоварни полного цикла и гастропаба

Готовый, 100% функциональный и адаптивный сайт для крафтовой пивоварни, паба или ресторана с собственной варней и смокером. Лендинг выполнен в индустриально-лофтовой стилистике с акцентами на открытую медь, состаренный кирпич, янтарный крафтовый солод и фирменные графические штампы.

## 🕒 Динамический статус работы бара

В верхнем баре (`top-bar`) и в блоке статистики Hero встроена функция `updateLiveWorkingStatus()`:
- Автоматически сверяет локальное время клиента с `hoursConfig`.
- Если бар открыт — отображает зелёный пульсирующий индикатор и текст вида: **«Открыто сегодня до 02:00»** (или до 00:00).
- Если закрыт — показывает статус **«Откроемся сегодня в 14:00»** или время открытия на следующий день.
- Обновляется каждую минуту в реальном времени без перезагрузки страницы.

## 🍻 Управление интерактивным кран-листом (Tap List)

Все сорта пива на кранах хранятся в массиве `TAP_LIST_DATA` в `script.js`. Чтобы добавить новый сорт или отредактировать имеющийся:

```javascript
{
  id: 1,
  tapNumber: '#01',
  name: 'MOSCOW DUST',
  style: 'New England Hazy Double IPA',
  category: 'ipa', // Варианты: 'ipa', 'stout', 'lager', 'wheat', 'sour'
  abv: 8.2,        // Крепость (число для фильтрации)
  ibu: 55,         // Горечь (число для фильтрации)
  og: '18.5%',     // Плотность начального сусла
  hops: 'Citra Lupomax, Mosaic, Galaxy',
  desc: 'Описание вкусового профиля и солодовой базы...',
  prices: { p33: '380 ₽', p50: '520 ₽', p100: '950 ₽' }
}
```

### Возможности кран-листа:
1. **Мгновенный живой поиск:** по названию, стилю, описанию или конкретному сорту хмеля (напр., *Citra* или *Stout*).
2. **Фильтрация по категориям:** *Все сорта*, *IPA & APA*, *Stout & Porter*, *Lager & Pilsner*, *Wheat & Rauch*, *Sour, Wild & Cider*.
3. **Фильтрация по ABV (крепости):** `< 5.5%` (легкое), `5.5% – 7.5%` (классика), `> 7.5%` (крепкое).
4. **Фильтрация по IBU (горечи):** `< 25 IBU` (мягкое), `25 – 50 IBU` (баланс), `> 50 IBU` (охмеленное).
5. **Сортировка:** по номеру крана, по возрастанию/убыванию крепости, по горечи и по цене.
6. **Кнопка добавления в дегустационный сет:** меняет состояние на «✓ В вашем сете».

## 🪵 Интерактивный конструктор дегустационного сета (Beer Flight Builder)

Позволяет гостю собрать фирменный дегустационный сет из **4 сортов по 150 мл** (890 ₽) на стилизованной деревянной доске:
- При клике на «+ В дегустационный сет» сорт занимает свободный слот на доске.
- Кнопка крестика на слоте удаляет сорт из сета.
- Доступны готовые пресеты от шеф-пивовара:
  - 💥 *Хмелевой удар (IPA Set)*
  - 🍫 *Темный бархат (Stouts)*
  - 👑 *Классика Европы (Lagers & Wheat)*
  - 🍒 *Ягодно-фруктовый фреш*
- При сборе сета активируется кнопка **«Заказать сет к столу»** — она открывает модальное окно бронирования стола и автоматически предзаполняет поле комментариев списком выбранных сортов.
- При прокрутке страницы вниз появляется плавающий док (`floating-flight-dock`) с текущим количеством выбранных сортов.

## 🗺️ Яндекс Карты (Yandex Maps 2.1)

Карта инициализируется в функции `initYandexMaps()`:
- Контейнер: `<div id="yandex-map"></div>`.
- Координаты берутся из `LANDING_CONFIG.coordinates` (`[55.772314, 37.618992]`).
- Метка стилизована под янтарный крафтовый цвет `islands#darkOrangeDotIcon` с подробным описанием в балуне.
- Встроен фоллбэк (`map-fallback`): если API Яндекс Карт заблокирован или отсутствует интернет-соединение, автоматически отображается карточка с адресом и кнопкой прямого перехода в приложение Яндекс Карт.

## 📸 Как заменить фотографии

В `index.html` все изображения снабжены комментариями с подсказками:
```html
<!-- КАК ЗАМЕНИТЬ ФОТО: Замените src на images/food-brisket.jpg -->
<img src="https://images.unsplash.com/photo-..." alt="Брискет из смокера">
```

### Рекомендуемые шаги:
1. Создайте папку `images/` рядом с `index.html`.
2. Поместите ваши фотографии с оптимизированным весом (WebP или сжатый JPG):
   - `hero-bg.jpg` (1920x1080) — фоновое изображение Hero-блока
   - `brewery-tanks.jpg` (1200x800) — варочные емкости
   - `food-brisket.jpg` (800x600) — брискет из смокера
   - `food-ribs.jpg` (800x600) — свиные ребра
   - `food-burger.jpg` (800x600) — фирменный бургер
   - `food-sausages.jpg` (800x600) — колбасный сет
   - `gallery-*.jpg` (800x600) — снимки паба и гостей для галереи
3. Замените ссылки `src="..."` на относительные пути `images/...`.
