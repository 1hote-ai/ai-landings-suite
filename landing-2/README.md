# VORTEX Athletic Club — Премиальный атлетический клуб

Премиальный, высокотехнологичный одностраничный сайт (Landing Page) для элитного фитнес-хаба и спортивного клуба.
Сайт выполнен в стилистике **High-Octane Dark Athletic Brutalism** с неоновыми кинетическими акцентами Electric Lime Volt (`#D4FF00`), глубоким матовым графитом (`#0E0F12`), соревновательными шрифтами `Syne` и `Plus Jakarta Sans`.

---

## ⚡ Особенности и ключевой функционал

1. **Единый конфигурационный объект (`LANDING_CONFIG`)**:
   - Все контактные данные (телефон, email, адрес, метро, паркинг, координаты, график работы, ссылки на соцсети) централизованно задаются в начале файла `script.js` и автоматически синхронизируются по всем элементам страницы с атрибутом `data-bind`.
2. **Динамический статус работы клуба ("Открыто сейчас" / "Скоро закрывается" / "Сейчас закрыто")**:
   - В режиме реального времени рассчитывает статус по московскому часовому поясу (UTC+3) с пульсирующим неоновым индикатором в шапке, мобильном меню, блоке контактов и футере.
3. **Интерактивный таймтейбл тренировок**:
   - Фильтрация по дням недели (ПН–ВС) с автоматическим определением сегодняшнего дня.
   - Фильтрация по категориям (Hyrox, Тяжелая атлетика / Eleiko, Бокс & Combat, Wattbike Cycling, Mobility & Rehab).
   - Индикаторы свободных мест (зеленый / оранжевый при остатке &le; 3 мест).
   - Кнопка «Записаться» автоматически открывает модальное окно с предзаполненным названием тренировки и назначенным тренером.
4. **Интерактивный калькулятор клубных карт**:
   - Переключатель периодов: 1 месяц, 6 месяцев (скидка 15%), 12 месяцев (скидка 25%) с мгновенным пересчетом цен и выгоды.
5. **Интеграция Яндекс Карт (API 2.1)**:
   - Асинхронная отложенная загрузка карты (IntersectionObserver) для сохранения максимальной скорости загрузки страницы.
   - Кастомная метка с неоновым цветом и карточкой клуба (адрес, телефон, режим, кнопка «Построить маршрут»).
   - Защищенный fallback со ссылкой на Яндекс Навигатор при отсутствии подключения к сети.
6. **Умная форма захвата лидов и бронирования**:
   - Маска для ввода российского номера телефона: `+7 (___) ___-__-__`.
   - Валидация полей (имя, телефон, чекбокс согласия).
   - Анимированный экран успешной отправки заявки и система всплывающих Toast-уведомлений.
7. **Адаптивность 100%**:
   - Плавное боковое меню (Drawer Nav) на мобильных экранах.
   - Мобильная плавающая панель (Sticky Bar) с кнопкой быстрой записи.

## 🛠 Руководство по редактированию

### 1. Изменение контактов, телефона и адреса

Откройте файл `script.js` и измените значения в объекте `LANDING_CONFIG`:

```javascript
const LANDING_CONFIG = {
  brand: {
    name: "VORTEX Athletic Club",
    tagline: "Элитный атлетический клуб нового поколения",
    // ...
  },
  contacts: {
    phone: "+7 (495) 829-40-10",       // Отображаемый номер
    phoneClean: "+74958294010",         // Номер для ссылки tel:
    email: "club@vortex-athletic.ru",   // Email клуба
    address: "Москва, ул. Большая Полянка, д. 28, стр. 1",
    metro: "м. Полянка / м. Третьяковская (3 мин пешком)",
    parking: "Собственный подземный отапливаемый паркинг на 60 машиномест",
    yandexNavigatorLink: "https://yandex.ru/maps/?rtext=~55.741556,37.620028"
  },
  // ...
};
```
После сохранения изменений скрипт автоматически обновит все телефоны, ссылки и адреса на сайте.

### 2. Настройка координат и метки Яндекс Карт

В `script.js` укажите точные географические координаты вашего здания:

```javascript
coordinates: [55.741556, 37.620028], // [Широта, Долгота]
```

Для построения прямого маршрута в навигаторе обновите ссылку:
```javascript
yandexNavigatorLink: "https://yandex.ru/maps/?rtext=~55.741556,37.620028"
```

В `index.html` в секции `#contacts` также можно обновить текстовые координаты:
```html
<span>Координаты: <strong>55.741556, 37.620028</strong></span>
```

### 3. Настройка графика работы клуба

В `script.js` в объекте `schedule` настройте часы открытия и закрытия:

```javascript
schedule: {
  weekdays: {
    openHour: 6,
    openMinute: 30,
    closeHour: 23,
    closeMinute: 30,
    text: "Пн — Пт: 06:30 – 23:30"
  },
  weekends: {
    openHour: 8,
    openMinute: 0,
    closeHour: 22,
    closeMinute: 0,
    text: "Сб — Вс: 08:00 – 22:00"
  },
  timezoneOffsetHours: 3 // Часовой пояс Москвы (UTC+3)
}
```

Скрипт автоматически:
- Определяет текущий день недели и время.
- Если клуб открыт: показывает зеленый пульсирующий индикатор и текст «Открыто сейчас • до 23:30».
- Если до закрытия осталось меньше 45 минут: переключает индикатор на оранжевый («Скоро закрывается»).
- Если клуб закрыт: переключает на красный («Сейчас закрыто • Откроемся в 06:30»).

### 4. Редактирование расписания тренировок

Расписание хранится в массиве `TIMETABLE_DATA` в `script.js`.
Каждая запись содержит:
- `id`: уникальный номер.
- `day`: день недели (`"mon"`, `"tue"`, `"wed"`, `"thu"`, `"fri"`, `"sat"`, `"sun"`).
- `category`: фильтр направления (`"hyrox"`, `"strength"`, `"combat"`, `"cycling"`, `"recovery"`).
- `time`: время проведения (например, `"07:30 – 08:30"`).
- `title`: название тренировки.
- `zone`: локация в клубе.
- `coachName`: имя тренера.
- `coachRole`: регалии тренера.
- `coachImg`: фото тренера.
- `spotsLeft`: сколько свободных мест осталось.
- `maxSpots`: общая вместимость группы.

Пример добавления новой тренировки:
```javascript
{
  id: 107,
  day: "mon",
  category: "strength",
  time: "21:00 – 22:15",
  title: "Bench Press & Chest Power",
  zone: "Eleiko Sanctuary // Помост 3",
  coachName: "Алексей Беркутов",
  coachRole: "МСМК по тяжелой атлетике",
  coachImg: "images/coach-1.jpg",
  spotsLeft: 3,
  maxSpots: 8
}
```

### 5. Замена фотографий и изображений

В коде `index.html` все изображения снабжены специальными комментариями вида:
`<!-- КАК ЗАМЕНИТЬ ФОТО: Замените src на images/... -->`

Чтобы использовать свои локальные фотографии:
1. Создайте папку `images/` внутри `landing-2/`.
2. Поместите туда ваши оптимизированные фото (`.webp`, `.jpg` или `.png`).
3. Замените URL в атрибуте `src` соответствующего тега `<img>`.

**Рекомендуемые разрешения:**
- Главный экран (Hero): `1920x1080px`, сжатие WebP/JPG ~80%, темная тональность.
- Направления тренировок: `800x500px` (пропорция 16:10).
- Зоны клуба: `1200x800px` или `1200x600px` для большой карточки.
- Фотографии тренеров: `600x750px` (портретная ориентация 4:5).

### 6. Редактирование цен на клубные карты

В `index.html` в секции `#memberships` каждая карточка тарифа содержит атрибуты цен:

```html
<span class="pricing-card__amount" 
  data-price-1="18000" 
  data-price-6="91800" 
  data-price-12="162000">
  18 000
</span>
```
- `data-price-1`: цена за 1 месяц.
- `data-price-6`: итоговая стоимость за 6 месяцев.
- `data-price-12`: итоговая стоимость за 12 месяцев.

Скрипт автоматически рассчитает ежемесячный эквивалент и процент выгоды при клике на кнопки «1 месяц», «6 месяцев», «12 месяцев».

### 7. Подключение отправки заявок (Telegram, CRM, Email)

В файле `script.js` в методе `handleFormSubmit(form)` реализована демонстрационная отправка с симуляцией сетевого запроса.
Чтобы подключить отправку в реальный Telegram-чат или webhook CRM (amoCRM / Bitrix24):

Замените блок `setTimeout` на вызов `fetch`:
```javascript
const payload = {
  name: nameInput.value.trim(),
  phone: phoneInput.value,
  direction: document.getElementById("form-direction").value,
  coach: document.getElementById("form-coach").value,
  timePreference: document.getElementById("form-time-pref").value
};

fetch("https://your-crm-webhook-url.com/api/lead", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify(payload)
})
.then(response => response.json())
.then(data => {
  // Показ экрана успеха
  if (formView) formView.hidden = true;
  if (successView) successView.hidden = false;
})
.catch(err => {
  VortexApp.showToast("Произошла ошибка при отправке. Пожалуйста, позвоните нам.");
});
```

## 🚀 Запуск и хостинг

Сайт полностью статичен и не требует сборки (Webpack, Vite или Node.js не требуются).

### Быстрый просмотр:
Просто откройте `index.html` в любом современном веб-браузере:
- Двойной клик на `index.html` или
- Через локальный сервер (например, VS Code Live Server или `python3 -m http.server 8000`).

### Деплой:
Вы можете загрузить папку на любой хостинг:
- **GitHub Pages**: включите Pages в настройках репозитория.
- **Vercel / Netlify**: перетащите папку в дашборд.
- **Nginx / Apache / Timeweb / Beget**: загрузите файлы в корневую директорию сайта.
