## 🗺️ 2. Настройка Яндекс.Карт

1. Откройте сервис [Яндекс Карты](https://yandex.ru/maps/) и найдите точный адрес вашей клиники.
2. Скопируйте координаты (например, `55.760241, 37.605332`).
3. В файле `script.js` обновите поле:
   ```javascript
   coordinates: [55.760241, 37.605332],
   ```
4. Обновите ссылку `socials.yandexMapsUrl` на вашу карточку организации в Яндекс Картах, чтобы при клике на мобильных устройствах сразу открывалось приложение «Яндекс Карты».
5. **Fallback:** Если у пользователя отключен интернет или заблокирован скрипт API Яндекс Карт, на месте карты автоматически отображается стилизованная карточка с кнопкой перехода в приложение.

## 📸 3. Замена фотографий на собственные

В коде `index.html` все изображения снабжены комментариями вида:
`<!-- КАК ЗАМЕНИТЬ ФОТО: Замените src на images/... -->`

Чтобы перевести сайт на локальные изображения:
1. Создайте папку `images/` в директории `landing-4/`.
2. Поместите туда оптимизированные фотографии в формате `.jpg` или `.webp`:
   - `images/hero-clinic.jpg` — главный баннер клиники (рекомендуемый размер 1200x900px)
   - `images/service-implants.jpg`, `service-veneers.jpg`, etc. — карточки услуг (800x500px)
   - `images/doctor-volkov.jpg`, `doctor-smirnova.jpg`, etc. — портреты врачей (600x700px)
   - `images/case1-before.jpg`, `case1-after.jpg` — клинические примеры До / После (600x400px)
   - `images/review-1.jpg`, etc. — аватары авторов отзывов (150x150px)
3. Замените URL Unsplash в атрибутах `src` на относительные пути (например, `src="images/hero-clinic.jpg"`).

## 🩺 4. Интерактивные компоненты

### 1. Экспресс-тест подбора лечения (Квиз)
- Секция `#quiz`.
- Реализован 4-шаговый опрос с динамическим прогресс-баром.
- Финальный шаг собирает имя, телефон и дарит подарок (бесплатное КТ и скидку).
- При отправке данные валидируются, телефон форматируется через маску `+7 (XXX) XXX-XX-XX`.

### 2. Запись к врачу на удобное время
- Секция `#booking`.
- Позволяет выбрать одного из 4 специалистов, услугу из выпадающего списка, дату (динамически рассчитываются 7 ближайших дней недели) и время приема.
- Сводка бронирования обновляется в реальном времени.

### 3. Модальное окно лидогенерации
- Модальное окно `#appointment-modal` открывается по клику на любую кнопку с атрибутом `data-open-modal`.
- Если кнопка содержит атрибут `data-service="Название"`, это название автоматически подставляется в форму.
- Поддерживает закрытие по клавише `Escape`, клику по фону или крестику.
- Встроен экран подтверждения заявки с промокодом на скидку `AURA-2026`.

### 4. Живой статус работы клиники («Открыто сейчас»)
- Скрипт каждую минуту проверяет московское время (UTC+3).
- В рабочие часы бейдж пульсирует зеленым цветом и показывает `Открыто сейчас (до 21:00)`.
- После закрытия бейдж автоматически переключается в режим `Сейчас закрыто • Откроемся в 09:00`.

## 🎨 5. Фирменная палитра и стили (`style.css`)

Все фирменные цвета вынесены в CSS-переменные в корне `:root`:

- `--color-white`: `#FFFFFF` — клинический белый
- `--color-navy`: `#0B2545` — глубокий медицинский синий
- `--color-turquoise`: `#139A8C` — мягкая морская бирюза
- `--color-seafoam`: `#EEF7F6` — нежная морская пена (фоны секций)
- `--color-platinum`: `#E0E7ED` — платиновый серебристый (рамки и разделители)

## 🚀 6. Подключение к CRM и отправка заявок

В функциях отправки форм (в `script.js`):
- `quizForm.addEventListener('submit', ...)`
- `bookingForm.addEventListener('submit', ...)`
- `modalForm.addEventListener('submit', ...)`

Для отправки лидов в amoCRM, Битрикс24 или Telegram-чат добавьте стандартный AJAX-запрос:

```javascript
fetch('/api/send-lead.php', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    name: nameInput.value,
    phone: phoneInput.value,

    doctor: selectedDoctor,
```
