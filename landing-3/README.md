# MONOLITH — Архитектурное бюро (Landing Page 3)

Современный посадочный сайт премиум-класса для архитектурно-строительного бюро и студии интерьеров, спроектированный в строгой швейцарской модернистской эстетике (Swiss Architectural Minimalism): модульная 12-колоночная сетка, массивные отступы («воздух»), микро-линии (hairlines), честные материалы и архитектурная типографика (Space Grotesk + Inter).

## 🖼️ Как заменить фотографии

В файле `index.html` все медиа-блоки снабжены явными комментариями:
`<!-- КАК ЗАМЕНИТЬ ФОТО: Замените src на images/... -->`

Рекомендуемые шаги:
1. Создайте в папке `landing-3` директорию `images/`.
2. Поместите туда ваши фотографии проектов в формате `.webp`, `.jpg` или `.png`.
3. В `index.html` замените ссылки Unsplash на локальные пути:
   - **Главное фото в Hero-секции:**  
     Замените `https://images.unsplash.com/...` в `<div class="hero-media__frame">` на `images/hero-villa.jpg`.
   - **Интерактивный слайдер До / После (`#baSlider`):**  
     * Слой «После» (`.ba-slider__after img`): Замените на `images/after-villa.jpg` (готовый объект).
     * Слой «До» (`#baBeforeImg`): Замените на `images/before-villa.jpg` (черновой монолит / стройка).
   - **Карточки проектов в портфолио (`#projectsGrid`):**  
     Замените пути в `<img class="project-card__img">` на `images/project-1.jpg`, `images/project-2.jpg` и т.д.
   - **Фотографии команды (`.team-grid`):**  
     Замените пути в `<img class="team-card__img">` на портреты сотрудников `images/team-1.jpg` и т.д.

## 🗺️ Настройка Яндекс Карт

1. Откройте `script.js`.
2. В секции `LANDING_CONFIG.contacts` измените координаты:
   ```javascript
   coordinates: [ШИРОТА, ДОЛГОТА],
   ```
   Например, для Санкт-Петербурга: `[59.938678, 30.314474]`.
3. Обновите ссылку `yandexMapsUrl`:
   `https://yandex.ru/maps/?pt=ДОЛГОТА,ШИРОТА&z=16&l=map` (обратите внимание: в ссылке Яндекс Карт параметр `pt` принимает сначала долготу, затем широту через запятую).
4. Если у вас есть персональный API-ключ Яндекс Карт, добавьте параметр `&apikey=ВАШ_КЛЮЧ` в тег `<script>` в `index.html`:
   ```html
   <script src="https://api-maps.yandex.ru/2.1/?lang=ru_RU&apikey=ВАШ_КЛЮЧ" type="text/javascript"></script>
   ```
5. **Отказоустойчивость:** Если скрипт карт недоступен (блокировщики, отсутствие сети), сайт автоматически отображает стилизованную карточку с точным адресом и прямой кнопкой перехода в приложение Яндекс Карт.

## 🧮 Настройка ставок и коэффициентов калькулятора

Логика калькулятора находится в функции `initProjectCalculator()` в `script.js`:
- Базовые ставки за м² задаются в кнопках направления:
  - Архитектура виллы: `4 500 ₽/м²`
  - Дизайн интерьера: `5 500 ₽/м²`
  - Комплексный проект: `8 000 ₽/м²`
  - Реконструкция: `6 000 ₽/м²`
- Процентные надбавки за авторский надзор (+15%), инженерные разделы (+20%) и комплектацию (+10%) можно отредактировать в разметке `index.html` через атрибуты `data-percent="..."` у чекбоксов, либо напрямую в коде `calculate()`.
- Фиксированная стоимость 3D-анимации настраивается атрибутом `data-fixed="120000"`.

При клике на кнопку «Зафиксировать смету и получить КП» рассчитанная сумма и параметры объекта автоматически передаются в скрытые поля формы модального окна.

## 📬 Обработка и сохранение заявок

Форма заявки включает:
- Строгую маску номера телефона `+7 (___) ___-__-__`.
- Валидацию обязательных полей (имя от 2 символов, полный номер телефона, чекбокс согласия).
- Имитацию отправки с индикатором загрузки и генерацией номера обращения (например, `#M-482`).
- Локальное сохранение данных в `localStorage` браузера по ключу `'monolith_leads'`.

### Интеграция с Telegram / CRM / Webhook:
В функции `initModals()` в файле `script.js` найдите блок:
```javascript
// Simulate network persistence to localStorage
setTimeout(() => {
  ...
}, 500);
```
Замените его на стандартный `fetch` запрос к вашему бэкенду или боту:
```javascript
fetch('https://api.your-backend.ru/leads', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(leadData)
})
.then(res => res.json())
.then(data => {
  // показать модалку успеха
});
```
