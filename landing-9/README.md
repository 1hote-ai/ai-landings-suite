# ROBO-START Академия — Лендинг детского центра робототехники и IT

Современный, адаптивный и конверсионный одностраничный сайт детской академии робототехники и программирования («ROBO-START Академия»).

- **Стек:** Semantic HTML5, Modern CSS3 (CSS Variables, Flexbox/Grid, Keyframes), Vanilla JavaScript (ES6+), Yandex Maps 2.1 API.
- **Шрифты:** Google Fonts (Nunito — заголовки, Montserrat — интерфейс и основной текст).
- **Цветовая палитра:**
  - Электрический кобальтовый синий: `#2563EB`
  - Солнечный манго желтый: `#FBBF24`
  - Коралловый пунш: `#F43F5E`
  - Мятный зеленый: `#10B981`
  - Облачно-белый фон: `#F8FAFC`
- **Никаких сторонних тяжелых фреймворков:** сайт загружается мгновенно, не требует сборки (Webpack/Vite) и готов к размещению на любом хостинге.

## 2. Как настроить Яндекс.Карту

1. Узнайте координаты вашего филиала (в [Яндекс.Картах](https://maps.yandex.ru) нажмите правой кнопкой мыши на здание → «Что здесь?» → скопируйте координаты).
2. Вставьте координаты в `LANDING_CONFIG.contacts.coordinates`:
   ```javascript
   coordinates: [55.733512, 37.662194],
   ```
3. Обновите ссылку на резервный маршрут `yandexMapsUrl`:
   ```javascript
   yandexMapsUrl: "https://yandex.ru/maps/?pt=37.662194,55.733512&z=16&l=map"
   ```
4. Если API карт временно недоступен или заблокирован блокировщиком рекламы, автоматически включится встроенная карточка-заглушка с кнопкой «Открыть в Яндекс.Картах».

## 3. Статус «Открыто сейчас» в реальном времени

В верхней панели сайта работает автоматический индикатор:
- В рабочие часы пульсирует зеленая точка: **«🟢 Открыто сейчас (до 20:00)»**.
- В нерабочие часы индикатор переключается в серый режим с текстом: **«Сейчас закрыто • Откроемся в 10:00»**.
- Время открытия и закрытия рассчитывается динамически по часам вашего региона из блока `schedule.days`.

## 4. Как заменить фотографии

В файле `index.html` все изображения снабжены комментариями с подсказкой:
`<!-- КАК ЗАМЕНИТЬ ФОТО: Замените src на images/... -->`

Для добавления собственных фотографий:
1. Создайте в папке проекта подпапку `images/`.
2. Поместите туда ваши изображения:
   - `images/hero-robotics.jpg` (главный баннер, 900×700px)
   - `images/course-wedo.jpg`, `images/course-spike.jpg`, `images/course-scratch.jpg`, `images/course-arduino.jpg`, `images/course-python.jpg`, `images/course-3d.jpg` (карточки курсов, 700×450px)
   - `images/mentor-alexander.jpg`, `images/mentor-daria.jpg` и т.д. (портреты наставников, квадратные 400×400px)
   - `images/gallery-1.jpg` – `images/gallery-6.jpg` (фотографии классов и уроков, 800×600px)
3. Замените в `index.html` атрибуты `src="..."` на локальные пути (например, `src="images/hero-robotics.jpg"`).

## 5. Интерактивный подбор курса (Тест-квиз)

Секция «Какой курс подойдёт именно вашему ребёнку» содержит мини-тест из 3 шагов:
1. Возраст ребёнка (5–7, 8–11, 12–16 лет)
2. Интерес ребёнка (LEGO, видеоигры, код, электроника)
3. Главная цель (хобби, IT-профессия, олимпиады)

При выборе любого варианта логика в `script.js` (`updateRecommendation()`) мгновенно рассчитывает оптимальный курс и обновляет карточку результата. При нажатии на кнопку **«Записаться на этот курс бесплатно»** открывается модальное окно, где:
- Нужный курс автоматически предвыбран в списке.
- Возрастная группа предвыбрана.
- Источник заявки помечается для администратора.

## 6. Форма записи и интеграция с CRM / Telegram

В модальном окне записи реализована строгая валидация:
- Имя родителя (минимум 2 символа).
- Номер телефона с автоматической маской `+7 (___) ___-__-__`.
- Выбор возраста ребёнка.
- Согласие на обработку персональных данных.

По умолчанию заявки логируются в консоль браузера и сохраняются в `localStorage.getItem('robostart_leads')`.

### Как подключить отправку в Telegram-чат:
В файле `script.js` найдите строку отправки формы (`form.addEventListener("submit", ...)`):
```javascript
// Пример отправки в Telegram Bot:
const BOT_TOKEN = "ВАШ_ТОКЕН_БОТА";
const CHAT_ID = "ВАШ_CHAT_ID";
const text = `🚀 Новая заявка на пробный урок!\nИмя: ${payload.parentName}\nТелефон: ${payload.phone}\nВозраст: ${payload.childAge}\nКурс: ${payload.course}\nИсточник: ${payload.source}`;

fetch(`https://api.telegram.org/bot${BOT_TOKEN}/sendMessage`, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ chat_id: CHAT_ID, text: text })
});
```

## 7. Размещение на хостинге

Сайт полностью статичен и не требует Node.js или базы данных:
- **GitHub Pages:** Загрузите репозиторий на GitHub, зайдите в *Settings → Pages* и выберите ветку `main`.
- **Vercel / Netlify:** Просто перетащите папку `landing-9` в личный кабинет Netlify Drop или импортируйте через Vercel CLI.
- **Обычный хостинг (Beget, TimeWeb, Reg.ru):** Загрузите содержимое папки в директорию `public_html/`.
