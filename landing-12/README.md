## 🚀 Быстрый запуск

Лендинг работает на чистом ванильном стеке (HTML5 + CSS3 + Vanilla JS) без сборщиков и тяжелых зависимостей:

### Вариант 1: Прямое открытие
Дважды кликните по файлу `index.html` или перетащите его в окно любого современного браузера (Chrome, Safari, Firefox, Edge).

### Вариант 2: Локальный веб-сервер (рекомендуется)
Для проверки Яндекс.Карт и корректных путей можно запустить легкий локальный сервер:

```bash
# С помощью Python 3
cd /Users/egor/Desktop/lendigs/landing-12
python3 -m http.server 8080

# Затем откройте в браузере:
# http://localhost:8080
```

## 📍 Настройка Яндекс.Карт

В `index.html` подключен официальный API Яндекс.Карт версии 2.1:
```html
<script src="https://api-maps.yandex.ru/2.1/?lang=ru_RU" type="text/javascript"></script>
```

Чтобы изменить точку на карте:
1. Откройте `script.js`.
2. Найдите строку `coordinates: [55.742389, 37.589112]` и вставьте координаты вашего салона (широта, долгота).
3. При необходимости скорректируйте масштаб в свойстве `mapZoom: 16`.
4. В `index.html` в блоке `#map-fallback` также замените прямую ссылку на Яндекс.Карты в атрибуте `href`:
   `https://yandex.ru/maps/?rtext=~ВАША_ШИРОТА,ВАША_ДОЛГОТА`.

## ⏰ Индикатор рабочего времени «Открыто сейчас»

В шапке, мобильном меню и в контактах расположен динамический индикатор статуса:
- В рабочее время отображается зелёная пульсирующая точка и надпись: `Открыто сейчас · до 22:00`.
- В нерабочее время статус автоматически меняется на `Закрыто сейчас · откроется в 10:00`.
- Расчёт ведется по московскому времени (UTC+3) с учётом дня недели (будни/выходные). Статус проверяется при загрузке и обновляется каждую минуту.

## 📸 Как заменить фотографии на собственные

Все изображения в `index.html` размечены специальными комментариями вида:
```html
<!-- КАК ЗАМЕНИТЬ ФОТО: Замените src на images/... -->
```

### Пошаговая инструкция:
1. Создайте в папке `landing-12` подпапку `images/`.
2. Поместите туда ваши фотографии интерьеров, мастеров и процедур (рекомендуемый формат: WebP или JPG с компрессией 80-85%).
3. В файле `index.html` найдите нужный тег `<img>` и замените `src="https://images.unsplash.com/..."` на локальный путь `src="images/ваше-фото.jpg"`.

### Основные фото-блоки:
1. **Первый экран (Hero):** `images/hero-sanctuary.jpg` (рекомендуемый размер 1920×1080).
2. **Философия / О нас:** `images/philosophy-details.jpg` (1000×660).
3. **Карточки ритуалов:** `images/ritual-*.jpg` (800×600).
4. **Мастера спа:** `images/team-*.jpg` (600×800 портретная ориентация).
5. **Галерея пространства:** `images/gallery-*.jpg` (1200×800).

## 🧮 Интерактивный калькулятор визита и онлайн-календарь

Лендинг включает в себя два синхронизированных интерактивных модуля:

1. **Калькулятор визита (`#calculator`):**
   - Выбор основной программы;
   - Переключение длительности (60 / 90 / 120 мин) с автоматическим пересчетом стоимости;
   - Выбор конкретного мастера с отображением его опыта;
   - Дополнительные опции (камни, купель, массаж головы, чайная церемония) с суммированием времени и цены;
   - Кнопка «Забронировать это время» сразу открывает модальное окно с уже выбранными параметрами!

2. **Модальное окно онлайн-бронирования (`#booking-modal`):**
   - Интерактивная лента ближайших 14 дней (автоматически рассчитывает дни недели и даты);
   - Выбор тайм-слотов (10:00, 11:30, 13:00 и т.д.);
   - Маска телефонного номера РФ: `+7 (___) ___-__-__`;
   - Проверка обязательных полей (имя от 2 символов, полный номер из 11 цифр, чекбокс согласия);
   - Имитация отправки с анимацией спиннера и выдачей персонального электронного талона визита (`SS-XXXXXX`).

В функции `initBookingForm()` в файле `script.js` подготовлена точка отправки формы:

```javascript
// Отправка данных на ваш сервер или вебхук Telegram
fetch("https://your-domain.ru/api/lead.php", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    name: nameVal,
    phone: phoneInput.value,
    ritual: ritual.name,
    master: master.name,
    date: BookingState.date,
    time: BookingState.time,
    totalPrice: document.getElementById("modal-selected-price").textContent,

```

Вы можете направить этот запрос в бота Telegram, Битрикс24, amoCRM или Yclients.
