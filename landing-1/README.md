# «Эфиопия & Зерно» — Премиальный лендинг спешелти ростери и слоу-бара

Готовый, адаптивный и высококонверсионный лендинг для кофейни третьей волны, независимого спешелти-обжарщика или дегустационного слоу-бара.

- **Стек**: Чистый семантический HTML5, современный модульный CSS3 (CSS Variables, Flexbox, Grid), нативный JavaScript (ES6+) без тяжелых внешних зависимостей.
- **Шрифты**: Google Fonts (*Playfair Display* для заголовков + *Outfit* для интерфейса).
- **Карты**: Интерактивные Яндекс.Карты 2.1 с кастомным маркером и резервной ссылкой маршрута.

## ⚙️ 1. Быстрая настройка контактов и режима работы (`LANDING_CONFIG`)

Все ключевые данные о компании вынесены в начало файла `script.js` в объект `LANDING_CONFIG`. При изменении этих значений они автоматически обновятся во всех блоках сайта (в шапке, футере, карточках контактов и ссылках звонка).

Откройте [script.js](file:///Users/egor/Desktop/lendigs/landing-1/script.js) и настройте параметры:

```javascript
const LANDING_CONFIG = {
  brand: {
    name: "Эфиопия & Зерно",                       // Название кофейни
    tagline: "Specialty Coffee Roastery & Slow Bar", // Подзаголовок
    city: "Москва",
    address: "ул. Покровка, 17, стр. 1, Москва",    // Фактический адрес
    metro: "м. Чистые пруды / Курская (7 мин)",     // Ближайшее метро
    phone: "+7 (495) 822-45-90",                   // Отображаемый телефон
    phoneRaw: "+74958224590",                       // Телефон для вызова tel:
    email: "hello@ethiopia-grain.ru"               // Электронная почта
  },
  
  // Координаты [широта, долгота] для Яндекс Карт
  coordinates: [55.755814, 37.617635],
  mapZoom: 16,

  // График работы для автоматического расчета статуса "Открыто сейчас"
  schedule: {
    weekdays: { 
      open: "08:00", 
      close: "22:00", 
      label: "Пн–Пт: 08:00 – 22:00" 
    },
    weekends: { 
      open: "09:00", 
      close: "23:00", 
      label: "Сб–Вс: 09:00 – 23:00" 
    }
  },

  // Ссылки на социальные сети и карты
  socialLinks: {
    telegram: "https://t.me/ethiopia_grain",
    vk: "https://vk.com/ethiopia_grain",
    yandexMaps: "https://yandex.ru/maps/-/CDT4E56"
  }
};
```

### Как работает статус «Открыто сейчас / Закрыто»:
Функция `updateWorkingHoursStatus()` в реальном времени определяет текущий день недели и время посетителя, сопоставляет их с часами открытия и автоматически переключает светящийся индикатор в шапке и блоке контактов:
- В рабочее время: зеленый пульсирующий индикатор и текст `● Открыто сейчас (до 22:00)`.
- В нерабочее время: янтарный индикатор и текст `○ Закрыто (откроемся в 08:00)`.

## 📸 2. Как заменить фотографии

В коде `index.html` все изображения снабжены подсказками в комментариях следующего вида:
`<!-- КАК ЗАМЕНИТЬ ФОТО: Замените src на images/... -->`

Чтобы использовать собственные фото:
1. Создайте папку `images/` внутри каталога `landing-1/`.

## 🗺️ 3. Настройка точки на Яндекс Картах

Карта инициализируется автоматически через API Яндекс.Карт версии 2.1.
1. Чтобы узнать точные координаты вашего заведения, откройте [Яндекс Карты](https://yandex.ru/maps), кликните правой кнопкой мыши по нужному дому и нажмите **«Что здесь?»** — координаты отобразятся в левой панели.
2. Вставьте полученные цифры в свойство `coordinates` в `script.js`:
   ```javascript
   coordinates: [55.755814, 37.617635],
   ```
3. При необходимости скорректируйте масштаб `mapZoom` (значение от 14 до 18).
4. Если вы хотите подключить собственный коммерческий ключ API Яндекс.Карт, в `script.js` в функции `initYandexMaps()` укажите:
   ```javascript
   script.src = 'https://api-maps.yandex.ru/2.1/?apikey=ВАШ_КЛЮЧ&lang=ru_RU';
   ```

## 📱 4. Телефонная маска и валидация формы

Форма быстрого заказа в модальном окне оснащена:
- Автоматической телефонной маской стандарта РФ: `+7 (___) ___-__-__` с корректной обработкой клавиши Backspace и вставки из буфера.

- Индикатором загрузки (спиннер на кнопке) и экраном успешного оформления с квитанцией выбранного лота.

## 🚀 5. Подключение отправки заявок в Telegram или CRM

В `script.js` в обработчике `leadForm.addEventListener('submit', ...)` симулируется отправка. Чтобы отправлять реальные уведомления бариста в Telegram-чат:

Замените блок `setTimeout` на прямой запрос к Bot API:

```javascript
const BOT_TOKEN = 'ВАШ_ТОКЕН_БОТА';
const CHAT_ID = 'ID_ВАШЕГО_ЧАТА';
const text = `☕ Новый заказ спешелти кофе!\n\n` +
             `• Позиция: ${coffeeInput.value}\n` +
             `• Имя: ${nameVal}\n` +
             `• Телефон: ${phoneInput.value}\n` +
             `• Способ связи: ${methodLabel}\n` +
             `• Пожелания: ${commentInput.value || 'Без комментария'}`;

fetch(`https://api.telegram.org/bot${BOT_TOKEN}/sendMessage`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ chat_id: CHAT_ID, text: text, parse_mode: 'HTML' })
}).then(() => {
  // Показать экран успеха
});
```

## 💻 6. Как запустить сайт локально

- **Вариант 1 (Простой)**: дважды кликните по файлу `index.html`, чтобы открыть его в любом браузере (Chrome, Safari, Firefox).
- **Вариант 2 (Через локальный сервер Python)**:
  ```bash
  cd /Users/egor/Desktop/lendigs/landing-1
  python3 -m http.server 8000
  ```
  После этого откройте в браузере: `http://localhost:8000`
- **Вариант 3 (VS Code / Antigravity)**: используйте расширение **Live Server** для мгновенного горячего обновления при сохранении файлов.
