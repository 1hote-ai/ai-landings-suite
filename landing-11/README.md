# KIZUNA (絆) — Ресторан высокой японской кухни Кайсеки и Омакасе

Премиальный, готовый к коммерческому запуску лендинг ресторана высокой японской кухни в эстетике ваби-саби, киотского минимализма, суми-э (тушь) и бамбуковых текстур с акцентами киновари (вермильон).

## ⚙️ 1. Быстрая настройка контактов и параметров (`LANDING_CONFIG`)

При изменении значений в этом объекте они **автоматически обновляются** во всей разметке:

```javascript

  // Контакты ресторана

  phoneRaw: "+74958221988",
  email: "reservations@kizuna-kaiseki.ru",
  address: "Москва, Страстной бульвар, 12, стр. 2",

    telegram: "https://t.me/kizuna_kaiseki",
```

## 📍 2. Настройка Яндекс Карт

1. Откройте `script.js`.
2. Найдите параметр `coordinates` в `LANDING_CONFIG`.
3. Укажите координаты вашего заведения: `[широта, долгота]`, например:
   ```javascript
   coordinates: [55.766114, 37.601245],
   ```
4. Для получения точных координат найдите адрес на [maps.yandex.ru](https://maps.yandex.ru), кликните правой кнопкой мыши по зданию и скопируйте координаты.
5. Интерактивная карта автоматически отобразит фирменную метку киноварного цвета с названием «KIZUNA (絆)», всплывающим окном с контактами и ссылкой на построение маршрута.
6. В случае отсутствия интернета или блокировки скриптов предусмотрен безопасный резервный блок (fallback) с прямой ссылкой на открытие локации.

## 🕒 3. Динамический статус работы («Открыто сейчас» / «Открыто с 13:00»)

В шапке сайта, мобильном меню и блоке контактов работает живой индикатор статуса:
- В рабочее время (Вт–Вс с 13:00 до 23:30): **«Открыто сейчас (до 23:30)»** (зеленый пульсирующий индикатор).
- До открытия (Вт–Вс до 13:00): **«Открыто с 13:00 (сеансы 18:00 & 21:00)»** (янтарный индикатор).
- Ночью после 23:30: **«Закрыто до 13:00 (завтра)»**.
- По понедельникам: **«Понедельник — день закупки на Тоёсу»** (выходной день, подготовка свежего улова).

Чтобы изменить рабочие часы или выходной день, отредактируйте параметры `openHour`, `closeHour` или `closedDay` в `LANDING_CONFIG.schedule`.

## 📷 4. Замена изображений и фотографий

Все фотографии в проекте снабжены специальными подсказками в HTML-комментариях вида:
`<!-- КАК ЗАМЕНИТЬ ФОТО: Замените src на images/... -->`.

Для замены фотографий на собственные:
1. Создайте папку `images/` внутри папки проекта `landing-11/`.
2. Поместите туда ваши оптимизированные фотографии в формате WebP или JPG (рекомендуемое качество: 80–85%, ширина для обложки: 1200–1600px, для галереи: 800–1000px).
3. В файле `index.html` найдите тег `<img>` по комментарию и замените `src`:

```html
<!-- КАК ЗАМЕНИТЬ ФОТО: Замените src на images/hero-omakase.jpg -->
<img 
  src="images/hero-omakase.jpg" 
  alt="Подача сета Кайсеки в ресторане KIZUNA" 
  class="hero-img"
>
```

Список ключевых изображений:
- **Главный экран (Hero)**: `hero-img` — подача блюда или суши-шеф крупным планом.
- **Шеф-мастер Кэндзи Танака**: `chef-img` — вертикальный портрет повара в традиционном кимоно.
- **Галерея (6 снимков)**: `gallery-thumb` (подача Оторо, стойка хиноки, чай матча, сашими, угли бинчотан, японский сад мхов).

## 🍣 5. Редактирование меню и дегустационных сетов

- Тексты блюд, состав подач и ингредиенты редактируются в секции `<section class="section menu-section" id="menu">` файла `index.html`.
- Меню разделено на три интерактивных таба:
  1. **Сет «Кайсеки Кидзуна» (9 подач — 18 500 ₽)** — подробная сетка подач от закуски *Сакидзуке* до ритуального супа и чая *Мидзумоно*.
  2. **Сет «Омакасе Гранд Премиум» (14 подач — 26 000 ₽)** — авторские подачи дикой рыбы Тоёсу и Вагю А5.
  3. **Сет «Сёджин Рёри» (8 подач — 14 500 ₽)** — вегетарианская монастырская дзен-традиция Киото.
- Блок сомелье: Саке-пейринг и чайная церемония редактируются в блоке `.pairings-card`.

## 📋 6. Форма бронирования стола и лидогенерация

Модальное окно бронирования открывается по кнопкам с атрибутом `data-modal="booking"`:
- Выбор сета (Кайсеки, Омакасе, Сёджин Рёри);
- Выбор даты визита (с ограничением: прошедшие даты заблокированы автоматически);
- Выбор сеанса (18:00 или 21:00);
- Выбор количества персон (1, 2, 3, 4 или аренда всей стойки на 12 гостей);
- Выбор сопровождения (саке-пейринг / чайный ритуал);
- Имя и фамилия гостя;
- Телефон с автоматической маской ввода `+7 (___) ___-__-__`;
- Поле для указания аллергий или особых пожеланий;
- Чекбокс согласия на обработку данных.

### Успешная отправка:
После заполнения форма отображает персонализированное окно с уникальным номером бронирования (например, `KZ-7482`), сводкой заказа и кнопкой мгновенного перехода в WhatsApp консьержа с уже предзаполненным сообщением для ускоренного подтверждения.

Для интеграции с CRM или Telegram-ботом просто добавьте вызов вашего API-эндпоинта (`fetch('/api/lead', { ... })`) в функцию `initBookingModal` в `script.js` (строка ~370).

## 🚀 7. Локальный запуск

Так как проект не содержит сборщиков и тяжелых зависимостей, его можно открыть любым удобным способом:

### Вариант 1: Через VS Code Live Server
Нажмите правой кнопкой мыши по файлу `index.html` &rarr; **Open with Live Server**.

### Вариант 2: Через Python
В терминале выполните:
```bash
cd /Users/egor/Desktop/lendigs/landing-11
python3 -m http.server 8000
```
Затем откройте в браузере: `http://localhost:8000`.

### Вариант 3: Через npx serve
```bash
npx serve /Users/egor/Desktop/lendigs/landing-11
```
