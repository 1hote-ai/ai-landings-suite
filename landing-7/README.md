# APEX Detail Studio — Премиальный автодетейлинг и керамическая защита

Профессиональный, полностью готовый к запуску и конверсионный одностраничный сайт (Landing Page) для премиальной детейлинг-студии.

- **Стек:** HTML5, CSS3 (Modern Flexbox/Grid, CSS Variables, Animations), Vanilla JavaScript (ES6+), Yandex Maps API 2.1.
- **Шрифты:** `Oswald` (заголовки, цифры, акценты) + `Inter` (основной текст) из Google Fonts.
- **Цветовая палитра:** 
  - Глубокий обсидиан (`#111113`)
  - Гоночный карминно-красный (`#E50914`)
  - Брашированный титан (`#9CA3AF`)
  - Оружейный металл Gunmetal (`#23252B`, `#1A1C22`)
  - Яркий белый (`#FAFAFA`)

## 2. Как заменить фотографии

Все изображения в `index.html` снабжены наглядными комментариями:
`<!-- КАК ЗАМЕНИТЬ ФОТО: Замените src на images/... -->`

Чтобы использовать собственные фотографии вместо ссылок Unsplash:
1. Создайте в папке `landing-7` подпапку `images/`.
2. Поместите ваши оптимизированные фото (`.webp`, `.jpg` или `.png`).
3. В файле `index.html` замените атрибуты `src`:
   - Главный экран (Hero): `src="images/hero-car.jpg"`
   - До / После: `src="images/before.jpg"` и `src="images/after.jpg"`
   - Услуги: `src="images/service-ppf.jpg"`, `src="images/service-ceramic.jpg"` и т.д.
   - Портфолио: `src="images/case-porsche.jpg"`, `src="images/case-bmw.jpg"` и т.д.

## 3. Настройка Яндекс Карты

1. Карта подключена через официальный API Яндекс Карт 2.1 в `<head>`:
   ```html
   <script src="https://api-maps.yandex.ru/2.1/?lang=ru_RU" type="text/javascript"></script>
   ```
2. Координаты метки задаются в `script.js` в `LANDING_CONFIG.contacts.coordinates`:
   ```javascript
   coordinates: [55.706117, 37.601552] // [Широта, Долгота]
   ```
   Узнать координаты вашего адреса можно на [yandex.ru/maps](https://yandex.ru/maps) — кликните правой кнопкой мыши по зданию и выберите «Что здесь?».
3. В `index.html` также есть ссылка-дублер для прямого построения маршрута в приложении Яндекс Карт:
   ```html
   <a href="https://yandex.ru/maps/?rtext=~55.706117,37.601552" target="_blank">...</a>
   ```

## 4. Интерактивные фичи

1. **Живой индикатор работы студии:**
   Скрипт проверяет текущее время (с учетом московского пояса UTC+3). Если время попадает в интервал `09:00 – 21:00`, вверху горит зеленый пульсирующий бейдж: `● Открыто сейчас (до 21:00)`. В нерабочее время статус плавно сменяется на: `○ Закрыто (откроемся в 09:00)`.
2. **Интерактивный ползунок «До / После»:**
   Позволяет клиенту двигать разделитель мышью или пальцем на смартфоне, сравнивая состояние ЛКП до детейлинга и после нанесения керамики 9H.
3. **Конфигуратор стоимости:**
   Клиент выбирает тип кузова, пакет и доп. опции. Цена пересчитывается в реальном времени. Кнопка «Зафиксировать цену и записаться» открывает модальное окно с уже подставленными параметрами выбранного комплекса.
4. **Маска ввода телефона:**
   Автоматически форматирует номер в стандарт `+7 (___) ___-__-__`.
5. **Фильтр портфолио:**
   Вкладки мгновенно сортируют проекты по категориям (PPF, керамика, интерьер) с плавной анимацией.
6. **Аккордеон FAQ:**
   Удобное раскрытие ответов на частые вопросы с автосворачиванием остальных элементов.

## 5. Запуск сайта

Сайт полностью автономен и не требует сборки (Webpack, Vite или Node.js не нужны).
Для локального просмотра:
- Откройте файл `index.html` двойным кликом в любом современном браузере (Chrome, Safari, Firefox, Edge).
- Либо запустите любой локальный HTTP-сервер:
  ```bash
  cd /Users/egor/Desktop/lendigs/landing-7
  python3 -m http.server 8080
  ```
  и перейдите по адресу `http://localhost:8080`.
